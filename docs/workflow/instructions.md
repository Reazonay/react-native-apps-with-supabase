# Instruktionen (Progressive Disclosure Stufe 2)

## Ziel
Setze die KI-Architektur gemaess Trigger um. Baue zuerst Discovery und Token-Extraktion,
anschliessend Agenten-Topologie, dann Skills.

## Regeln
- Arbeite CDD-first (Atomic Design).
- Neue UI nur ueber Tokens und Storybook validieren.
- Kontext sauber halten; nur die benoetigten Referenzen laden.

## Deliverables
- Design Tokens JSON
- UI-Inventar JSON
- Agenten-Topologie Dokument
- Skill-Spezifikationen
- Roadmap und Status
