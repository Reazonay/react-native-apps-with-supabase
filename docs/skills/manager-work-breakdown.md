# Skill: Manager - Work Breakdown

## Ziel
Roadmap erzeugen und Task-State verwalten.

## Inputs
- Trigger YAML
- Instruktionen
- Status (falls vorhanden)

## Outputs
- Roadmap
- Task-State (Backlog, In-Progress, Done)
- Validierungsplan

## Regeln
- Arbeite in Meilensteinen.
- Jede Phase mit klaren Deliverables.

## Validierung
- Roadmap deckt alle Phasen ab
- Tasks sind nachvollziehbar und priorisiert
