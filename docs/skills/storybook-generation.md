# Skill: Storybook Generation

## Ziel
CSF Stories erzeugen, damit jede AI-UI isoliert verifiziert werden kann.

## Inputs
- Komponentenliste
- Tokens
- UI-States

## Outputs
- CSF Stories
- Metaobject + Storyobjects + Decorators

## CSF Struktur (Pflicht)
1. Title
2. Metaobject
3. Storyobjects
4. Decorators

## Validierung
- Storybook laeuft ohne App-Start
- Alle Varianten sichtbar
