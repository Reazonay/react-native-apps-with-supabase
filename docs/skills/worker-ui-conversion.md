# Skill: Worker - UI Conversion

## Ziel
UI-Komponenten entlang Tokens und Atomic Design umsetzen.

## Inputs
- Instruktionen
- Freigegebene Referenzen (Tokens, Mapping)
- Akzeptierte Komponentenliste

## Outputs
- Neue/angepasste Komponenten
- Tests/Stories
- Update am UI-Inventar

## Regeln
- React/React Native beachten: Flexbox default vertical.
- Komponenten zuerst isoliert bauen.

## Validierung
- Storybook zeigt alle States
- Design Tokens eingehalten
