# Skill: Skill Generator (Meta)

## Ziel
Neue Skills definieren, anpassbar an neue Systeme.

## Inputs
- Zielsystem
- Rollenbeschreibung
- Input/Output-Format

## Outputs
- Neue Skill-Spezifikation
- Versionierungshinweis

## Regeln
- Skills sind minimal, klar und validierbar.
- Jede Spezifikation enthaelt Inputs, Outputs, Regeln und Validierung.
