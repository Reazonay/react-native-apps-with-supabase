# Skill-Spezifikationen

Diese Dokumente definieren Rollen, Inputs, Outputs und Validierungskriterien fuer die KI-Agents.

- Planner: Project Discovery + Token-Extraktion
- Manager: Work Breakdown + Task-State
- Worker: UI Conversion
- Storybook Generation: CSF Strukturen erzeugen
- Skill Generator: neue Skills generieren
